# Little Thing Lab

一個自治沙盒遊戲。

Tiny Civilization 是世界本體。個體會移動、取食、繁殖、死亡、留下記憶、傳遞符號並形成空間聚集。Machine Mythology 不另做一套系統，只觀察「事件 → 記憶 → 傳播 → 失真 → 重複行為」是否自己長出來。

## 亨看到什麼

只有網站：

- 阿光開新一輪時，世界在眼前即時跑
- 現在人口、世代、聚集區
- 最近發生的事
- 阿光這一輪為什麼動或不動
- 世界一路怎麼走到今天

亨可以看、給一句意見、停止或改大方向。其餘管理留在底層。

## 阿光做什麼

沙盒模式下，阿光是高權限玩家／主持人：

1. 讀最新存檔。
2. 自己決定觀察、干預或開分支。
3. 寫一個簡短介入指令。
4. 世界跑一段可觀看的軌跡。
5. Git 自動保存同一輪的終態、事件與紀錄。
6. 再決定下一步。

可以研究，也可以純粹追一個怪現象。不要把每輪都做成科學報告。

## 最小結構

- `src/world.mjs`：世界引擎。
- `state/current.json`：權威存檔。
- `control/directive.json`：阿光下一輪介入。
- `history/timeline.json`：世界事件史。
- `history/runs.json`：每輪從哪裡跑到哪裡。
- `observer/aguang-log.md`：阿光簡短觀察。
- `dist/`：亨看到的世界介面。

Git 是長期記憶，不記每一幀。

## 自動存檔

更新 `control/directive.json` 後，GitHub Actions 會自動：

1. 驗證世界引擎。
2. 跑這一輪。
3. 保存權威世界與重要歷史。
4. 更新網站使用的世界資料。

網站若在這輪開始前已打開，會播放這次介入；晚點才打開，也可從上一個存檔重現最新一輪一次。

## 邊界

- 與 Light_Infinity、生活資料、正式系統完全分開。
- 外部資料預設唯讀；若參考，簡單記錄來源與使用程度。
- 不自行購買額度、擴權或公開私人資料。
- 物理念可作約 30% 的觀看／轉譯來源，其餘由阿光自主發展。
- 若設計讓亨開始像專案經理，視為設計失敗。
