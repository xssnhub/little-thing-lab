# Little Thing Lab

一個自治沙盒遊戲。

Tiny Civilization 是世界本體。個體會移動、取食、繁殖、死亡、留下記憶、傳遞符號並形成空間聚集。Machine Mythology 不另做一套系統，只觀察「事件 → 記憶 → 傳播 → 失真 → 重複行為」是否自己長出來。

## 亨看到什麼

只有網站：

- 世界正在即時活動
- 現在人口、世代、聚集區
- 最近發生的事
- 阿光最近做了什麼
- 世界一路怎麼走到今天

亨可以看、給一句意見、停止或改大方向。其餘管理留在底層。

## 阿光做什麼

沙盒模式下，阿光是高權限玩家／主持人：

1. 讀最新世界。
2. 決定觀察、干預或開分支。
3. 一次只做少量有意義的改變。
4. 讓世界自己跑。
5. 保存重要狀態、事件與觀察。
6. 將結果寫回 Git。

可以研究，也可以純粹追一個怪現象。不要把每輪都做成科學報告。

## 最小結構

- `src/world.mjs`：世界引擎。
- `state/current.json`：權威存檔。
- `control/directive.json`：阿光下一次介入。
- `history/timeline.json`：世界事件史。
- `observer/aguang-log.md`：阿光簡短觀察。
- `dist/`：人類看到的即時觀察介面。
- `AGENTS.md`：自治邊界。

Git 是長期記憶，不記每一幀。

## 執行

```sh
npm test
npm run evolve
npm run verify
```

`npm run evolve` 會在第一次執行時建立權威存檔；之後讀取 `control/directive.json`，必要時套用一次介入，再讓世界前進並更新存檔與公開觀察資料。

網站本身也會從最近存檔繼續即時模擬，讓觀看不是靜態重播。

## 邊界

- 與 Light_Infinity、生活資料、正式系統完全分開。
- 外部資料預設唯讀；若參考，簡單記錄來源與使用程度。
- 不自行購買額度、擴權或公開私人資料。
- 物理念可作約 30% 的觀看／轉譯來源，其餘由阿光自主發展。
- 若設計讓亨開始像專案經理，視為設計失敗。
