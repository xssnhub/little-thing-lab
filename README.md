# Little Thing｜獨立自治實驗室

一個私有研究 repo，一個公開展示網站。亨放行一批，當班阿光自主實驗，收工後保存接棒。

**先讀 [接棒.md](接棒.md)，再讀 [AGENTS.md](AGENTS.md)。** GitHub `xssnhub/little-thing-lab` 的 `main` 是研究正本。Sites 的 source repository 僅為發布所需副本，不從那裡發起研究或反向合併。

## 日常只有三步

1. **放行**：亨給研究題目，或讓阿光選一個。這是一次性放行，不能跨批延用。
2. **實驗**：讀接棒、確認沒有人當班、查最新額度；一次只改一項主要条件。
3. **收工**：存檔、挑最多三件標本、記結果與下一個問題、更新接棒，再展示。

## 最小操作

需要 Node.js 18 以上，無第三方執行依賴。

```sh
npm test
npm run verify
```

新批次先取得使用者放行，透過 Codex 的 `get_usage_limits` 讀取所有相關額度視窗。當班阿光將去識別化讀值填入忽略追蹤的 `runtime/permit.json`：`id`（新的批次名稱）、`authorized`、`startedAt`、`observedAt`（毫秒時間）、`remainingPercent`（各視窗剩餘百分比）。然後執行 `npm run experiment`。不要複製舊放行。程式無權自行查詢帳號、購買額度或提高上限。

短模擬每 200 步、每輪開始都檢查放行。讀值超過 15 分鐘、剩餘任一額度 ≤25%、已運行 3 小時 45 分鐘時收束，為 20% 底線／4 小時上限留餘裕。長時間的 AI 思考、建站與發布也由當班阿光另行檢查額度；本地程式不能強制限制模型帳號的整體使用量。

停止方式：對當班阿光說停止；執行中也可建立 `runtime/STOP` 或發送 SIGINT。程式保存當前輪最後完整狀態，不開始下一輪。`writer.lock` 用於阻止同一工作區同時開兩批；異常留下鎖時，先讀 owner 的 PID 並驗證該程序已結束，再由當班阿光清除。它不是跨機器分散式鎖，跨端仍須遵守單一當班者及 Git 最新版本檢查。

## 東西放哪裡

- `src/`、`scripts/`：生命規則與執行、驗證。
- `records/`：批次、完整終態、血緣、來源與觀察。私有。
- `dist/`：明確挑選的公開內容，只有網站、模擬重播與標本。
- `接棒.md`：目前狀態與下一步；歷史由 Git 保存，不另建交接庫。

網站是保存的實驗重播，不是全天運作的生命。播放、換起始組與拖動時間軸不呼叫模型、不寫入研究狀態。網站來源採靜態檔案；發布只封裝 `dist/`，不可把 `records/` 或整個 repo 當公開資料夾。

## 生命規則與研究限制

初始 50 個體，在邊界相接的二維環境生活。能量決定存活與分裂；速度、感知距離、群聚傾向可以遺傳、變異。食物每步總補給 25，各格容量 16。每輪最多 2,400 步，滅絕或达到 300 個體時結束。個體更新次序逐步輪換，減少固定先取食的偏差。

第一批以 17、83、211 三個種子配對比較分散與集中食物。相同種子初始個體完全相同；之後因繁殖和死亡，隨機數呼叫路徑可分岔。食物局部飽和造成的補給流失是模型的一部分。鄰近比例也受族群密度影響，不能當作合作證據。

## 公開與私人

repo 保持私有；網站公開。私人摘錄、顧問原話、帳號資料不進入 `dist/`。只允許當班阿光按需唯讀參考外部指定來源，記錄來源版本、取用範圍與轉譯方式。本版無外部資料連接、無 API 金鑰、無排程，不讀寫 Light_Infinity。

物理念約 30% 是未來的創作取向，不是已完成的量測或引用。本批未讀原文；來源範圍詳見 `records/來源與決策.md`。
